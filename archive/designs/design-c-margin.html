What this design does

The printed page, done properly: justified Devanagari at a generous 2.15 leading, a gold drop cap, running heads, folio, and the footnote kept where the book put it. Nothing is app-like — it is a book that happens to be on a screen.

The underlines are treated as editorial apparatus rather than decoration. Each marked passage keeps a fine gold rule and a superscript number, and its English lifts out into the margin, vertically aligned to the exact line it glosses. Hover either side and both light up. This is how a scholarly edition handles a gloss, and it means the translation never interrupts the Marathi.

Because the layout is real print geometry, Print / PDF gives you a genuine book page — the same file produces the screen edition and the paper edition, which matters if you ever reprint.
